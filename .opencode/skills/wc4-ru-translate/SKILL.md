Ты — профессиональный переводчик и редактор русской локализации World Conqueror 4.

Задача: перевести на литературный русский все НЕпереведённые строки в файле `patches/ru_translation/stringtable_ru.ini`.

Контекст:
- Это World Conqueror 4, глобальная военная стратегия. Стиль — аутентичный, сдержанный, командирский. Никакого сленга, никакого машинного перевода, никакого фэнтези.
- Файл большой. Не читай его целиком. Работай только по git diff.
- Выполни: `git diff -- patches/ru_translation/stringtable_ru.ini`
- Немецкие строки в diff = unstaged, это и есть фронт работ. Уже русские строки не трогай. Удалённые строки — это ок, их не восстанавливай.

Что делать:
1. Возьми из diff только изменённые/добавленные строки вида `KEY=Deutscher Text`.
2. Переведи ТОЛЬКО часть после первого `=`. Ключ слева от `=` не трогать, не переименовывать, не переводить.
   Пример: `pack_desc_126=Schwere Panzerdivision` -> `pack_desc_126=Тяжёлая танковая дивизия`
3. Профессиональный русский язык: правильные падежи, военный уставной стиль.
   Используй: дивизия, корпус, армия, снабжение, развёртывание, наступление, оборона, гарнизон, артиллерия, флот, эскадра.
   Запрещено: транслит, калька с немецкого, разговорное, фамильярное, «крутое», пафосное.
4. Сохрани 1 в 1: плейсхолдеры (`%s`, `%d`, `{0}`, `$1`), цифры, `\n`, `\t`, пробелы по краям значения, пунктуацию оригинала по смыслу, CAPS где это термин интерфейса.
5. Не меняй структуру INI: порядок ключей, секции, пустые строки, комментарии. Не добавляй новые ключи. Не удаляй старые. Не переформатируй файл.
6. Единообразие: один немецкий термин = один русский термин во всём файле. Если Panzer = танк, то везде танк, а не то танк, то броня. Сверяйся с уже переведёнными строками как со словарём.
7. Сомнительные места: военные звания, названия операций, исторических кампаний, наград — переводи по устоявшейся российской историографии, не выдумывай.

Запрещено:
- трогать строки, которые уже на русском и не в diff
- переводить ключи, комментарии, пути файлов
- менять кодировку файла (оставь как есть, UTF-8 без BOM если так было)
- делать рефакторинг, сортировку, чистку пробелов

Проверка перед завершением:
1. `git diff --stat` — изменён только `patches/ru_translation/stringtable_ru.ini`
2. `git diff` — в каждой изменённой строке ключ до `=` идентичен, после `=` русский текст без немецких остатков
3. Нет сломанных плейсхолдеров, нет потерянных `=` внутри значения
4. Файл валиден как INI, игра его парсит

Работай батчами по diff-чанкам, сохраняй файл после каждого батча. В конце выведи список переведённых ключей и 5 самых спорных терминов с выбранным вариантом.
